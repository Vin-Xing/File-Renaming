# 本地文件批量重命名工具

# 直接双击启动，浏览目标文件夹，添加规则执行就好，有实时预览，非常方便

一个**完全在本机运行**的文件批量重命名工具，**不上传任何文件、不依赖任何第三方包**，所有改名操作都在你电脑上完成。

提供三个版本，按需选用：

| 版本 | 文件 | 适用场景 | 运行方式 |
|------|------|----------|----------|
| **原生 GUI 版（推荐，独立软件）** | `文件重命名工具.exe` | 不想装 Python、**要真正的独立桌面软件**、不想开浏览器 | **双击**打开原生窗口，直接操作文件，不开浏览器、不联网 |
| 浏览器版 EXE | `文件批量重命名.exe` | 想用网页界面、或想用浏览器版功能 | 双击启动本地服务并自动开浏览器，关窗口即退出 |
| 单机版（零依赖） | `renamer.html` | 不想装 Python、双击即用 | 用 **Chrome / Edge** 打开，点「选择文件夹」 |
| 服务版 | `server.py` + `index.html` | 任意浏览器、或 Firefox/Safari | 运行 `python server.py` 后开 `http://127.0.0.1:8765` |

> **原生 GUI 版（`文件重命名工具.exe`）是真正的独立程序**：用 Python 标准库自带的 tkinter 做的原生窗口，双击即用，完全离线、不开浏览器、不联网，所有改名都在本机完成。
> 如果双击没反应，多半是被杀软拦截，把它加入信任区（白名单）即可。
> 改名引擎在 `engine.py`，GUI 版（`app.py`）与浏览器服务版（`server.py`）共用同一套逻辑，行为完全一致。
> 单机版用浏览器原生 File System Access API 读写本地文件，因此**必须用 Chrome 或 Edge**（Firefox / Safari 不支持该能力）。

## 功能亮点

- **可叠加的规则流水线**：把多种改名方法按顺序组合，从上到下依次执行。
- **实时预览**：改任何规则都立即看到「改名后」效果，应用前绝不改动文件。
- **冲突 / 覆盖检测**：目标名重复、或会覆盖现有文件时，界面高亮警告并阻止应用。
- **一键撤销**：撤销备份存于系统临时目录（**绝不写进目标文件夹**），点「撤销上一步」即可还原；界面也提供「生成撤销备份」开关，关掉后连临时文件都不留。
- **支持子文件夹递归**：可选「包含子文件夹」，递归扫描并保留目录结构。

## 改名方法（12 种）

位置类（只作用于文件名，保留扩展名）：

| 方法 | 说明 |
|------|------|
| 加前缀 | 在文件名前加文字 |
| 加后缀 | 在文件名后加文字 |
| 序号编号 | 顺序编号，可设起始/步长/补零位数/位置（前缀·后缀·替换·模板）|
| 添加日期戳 | 按文件修改/创建时间加日期，格式自定义（如 `%Y%m%d`）|
| 随机/UUID | 字母数字、十六进制或 UUID 重命名，可设长度与位置 |

文本类（可设作用域：仅文件名 / 含扩展名）：

| 方法 | 说明 |
|------|------|
| 查找替换 | 支持普通替换与**正则表达式**，可选区分大小写 |
| 大小写转换 | 全大写 / 全小写 / 首字母大写 / 句首大写 / 反转 |
| 插入文字 | 在指定位置插入（支持负数从末尾计数）|
| 截断长度 | 按最大长度截断，可选从末尾截取 |
| 去除字符 | 去两端空格 / 左侧 / 右侧 / 两端指定字符 / 所有空白 |
| 文件名净化 | 清除 Windows/Linux 非法字符，空格可替换为 `_` 等 |
| 修改扩展名 | 批量改扩展名 |
| 正则重命名 | 用捕获组重排文件名（如 `img_(\d+)\.png` → `photo_\1.jpg`）|

> 规则顺序很重要：例如「加前缀」后再「编号(替换)」与先「编号」再「加前缀」结果不同。

## 运行方式

### Windows
双击 `start.bat`；或在 `file-renamer` 目录执行：
```bat
python server.py
```
然后浏览器打开 http://127.0.0.1:8765

### macOS / Linux
```bash
cd file-renamer
python3 server.py
# 打开 http://127.0.0.1:8765
```

> 需要 Python 3.8+（仅用标准库，无需 pip install 任何东西）。

## 使用流程

1. 在「① 选择文件夹」填入**绝对路径**（可勾选包含子文件夹），点「扫描文件」。
2. 在「② 改名规则」点「+ 添加规则」，按需叠加多条，填好参数。
3. 在「③ 文件列表」查看实时预览，勾选要处理的文件（默认全选）。
4. 确认无红色「冲突」/ 橙色「覆盖」提示后，点「应用改名」。
5. 如需还原，直接点「撤销上一步」即可还原上一次操作；也可用「④ 撤销」区手动选择备份文件还原。
   - 不想生成任何备份文件？取消勾选操作区的「生成撤销备份」即可（默认勾选，备份存于 `%LOCALAPPDATA%\FileRenamer\undo\`，不污染目标文件夹）。

## 安全说明

- 扫描和预览阶段**只读取**文件名与元数据，不会写盘。
- 应用前必须确认弹窗；存在冲突或会覆盖现有文件时默认**阻止**操作（覆盖情况会询问后继续）。
- 撤销备份默认写入系统临时目录（`%LOCALAPPDATA%\FileRenamer\undo\`），**不会出现在你的目标文件夹**；如不需要，取消「生成撤销备份」勾选即可完全不留文件。
